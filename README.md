# Plagiarism and Code Similarity Detector

## 1. Project Description

The Plagiarism and Code Similarity Detector is a Python-based application designed to identify similarities between programming source code files.

The system allows users to upload multiple code files and analyzes them to identify matching or similar code segments. It helps teachers and educational institutions detect potential code plagiarism in programming assignments.

## 2. Problem Statement

In educational institutions, students sometimes submit programming assignments containing copied or highly similar code.

Manually checking multiple programming files is time-consuming and difficult.

Our project provides an automated solution that compares source code files and generates similarity results to help identify potential plagiarism.

## 3. Project Objectives

- Detect similarities between programming source code files.
- Automate the code comparison process.
- Reduce manual checking time.
- Display similarity percentages.
- Help teachers analyze programming assignments.

## 4. Technologies Used

- Python
- Streamlit
- Python Libraries

## 5. Project Features

- Upload programming source code files.
- Preprocess source code.
- Compare multiple code files.
- Calculate code similarity.
- Display similarity results.
- Generate comparison reports (if supported).

## 6. Project Workflow

1. User uploads source code files.
2. The system reads the uploaded files.
3. Source code is preprocessed.
4. The system generates code representations.
5. Similarity algorithms compare the files.
6. Similarity results are displayed to the user.

## 7. Installation Requirements

Make sure you have installed:

- Python 3.10 or later (depending on project compatibility).
- pip
- Required Python libraries.

## 8. Installation Instructions

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

**Step 2: Open the project folder**

```bash
cd Plagiarism-and-Code-Similarity-Detector
```

**Step 3: Install dependencies**

```bash
python -m pip install -r requirements.txt
```

## 9. How to Run the Project

Execute the following command:

```bash
python -m streamlit run main.py
```

The application will open in your default web browser.
